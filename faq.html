Platforms

{% capture body %}

Currently Stride's editor is only available on Windows. However, you are able to write code and build games on Linux and macOS without it, which makes it possible to create code-only projects using the community toolkit.

Linux users can also use Game Studio via Proton. For more information, visit our official Proton setup guide in the documentation.

{% endcapture %} {% include accordion-item-faq.html id:"question-which-platforms-make" title:"On which platforms can I make games?" body:body %} {% capture body %}

Cross-platform editor rewrite

{% capture body %}

It's difficult to estimate when the editor will be ready for public use.

Stride is driven by the community and its contributors, who work on the engine mostly for free in their spare time. If you'd like to help with the rewrite, you can either donate to us on Open Collective or contribute code to one of the issues listed in the Avalonia Editor Rewrite project on GitHub.
